# GSD Project Guide: XLR8Hire

## Context
XLR8Hire is an AI-driven reverse recruitment platform. This project uses Next.js 16 (App Router), Tailwind v4, and Framer Motion. The current goal is a July 13th demo of an end-to-end AI interview flow.

## Workflow Status
- **Current Phase:** Phase 1 (Cinematic UI & Prototypes)
- **Mode:** yolo
- **Granularity:** coarse

## Critical Rules
1. ICONOGRAPHY: Use 'lucide-react' ONLY. Never use Material Symbols.
2. MOTION: Use 'src/lib/motion.ts' for all variants.
3. STYLING: Tailwind v4 (@theme) in globals.css.
4. PORTALS: Maintain 'Calm Intelligence' design across Student and Company portals.
